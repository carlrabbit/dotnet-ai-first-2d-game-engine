# Signal Passage review notes

- `signal-passage-launch.png` is an exported graphical launch capture showing every required visual class and the HUD/prompt language.
- The synthesized WAV inventory is generated from the six consumer-owned definitions under `consumers/signal-passage/game-content/sound-synthesis/`; each output has deterministic provenance in the synthesis artifacts.
- Interactive controls: arrows/WASD move; `E` opens containers or activates the mechanism; `F5` saves; `F9` loads; Escape closes.
- The save payload retains health, fragments, opened containers, mechanism, exit, and completion state; it intentionally omits transient prompt/feedback text.
