# Stable IDs

## Authority

This document is authoritative for stable ID principles.

Important objects require durable IDs, including entities, components, commands, events, queries, assets, textures, tiles, tilesets, maps, markers, animations, materials, shaders, UI controls, dialogue nodes, quest steps, scenarios, validators, save fields, and requirements.

IDs must not depend on filenames, display names, hierarchy positions, or visual coordinates.
