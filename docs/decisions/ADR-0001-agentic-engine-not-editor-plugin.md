# ADR-0001 — Build an agentic engine, not an editor plugin

## Status

Accepted.

## Decision

The project is a 2D game engine designed from the beginning for agentic development, not a Godot plugin and not a traditional editor-centric engine.

## Consequences

- Headless operation is primary.
- Structured project data is source truth.
- Scenario validation and artifact generation are product features.
- A graphical editor may exist later but is not foundational.
