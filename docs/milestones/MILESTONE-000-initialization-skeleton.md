# Milestone 000 — Initialization Skeleton

## Goal

Create a repository skeleton that captures the project thesis, active documentation structure, research inputs, and future setup path without prematurely creating scripts or .NET projects.

## Scope

- Root `README.md`.
- `AGENTS.md`.
- Active docs for terminology, specs, architecture, decisions, engineering, milestones, scenarios, content, artifacts, human review, and research.
- Placeholder folder structure for `eng/`, `src/`, `tests/`, `artifacts/`, and `game/`.
- Research copies of the attached guides and project summary.

## Non-goals

- No `.slnx`, `.sln`, or `.csproj` files.
- No executable `eng/` scripts.
- No package references.
- No CI workflows with real commands.

## Validation tier

Tier 0: structural/edit sanity.

## Done criteria

- No non-root `README.md` files.
- Research docs are present under `docs/research/`.
- Active docs state that research docs are non-authoritative.
- The skeleton can be committed as the starting repository state.
