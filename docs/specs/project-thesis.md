# Project Thesis

## Authority

This document is authoritative for the core project thesis.

## Thesis

The project is a .NET-based 2D game engine for agentic development.

Humans design, review, and make creative decisions. AI agents implement, modify, validate, and iterate on the game through structured commands, deterministic scenarios, semantic asset pipelines, validated behavior modules, source-generated runtime plumbing, and reproducible debug/release builds.

## Consequences

- A graphical editor is not essential initially.
- The engine must expose a headless CLI/API.
- Structured data is preferred over hidden editor state.
- Runtime inspection and artifacts are core features.
- Scenario validation is part of the product, not an external afterthought.
