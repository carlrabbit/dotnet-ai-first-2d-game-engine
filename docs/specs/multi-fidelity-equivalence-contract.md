# Multi-Fidelity Equivalence Contract

## Authority

Authoritative for M033 comparison, tolerance, conservation, and observer-neutrality evidence.

## Classes

### Rule-equivalent

Zero divergence for quantities, capacity, eligibility, priorities, reservations, activity legality, command semantics, thresholds, lifecycle, and identity.

### Bounded-approximate

Declared tolerances for travel duration, completion instant, arrival order, blockage delay, and interruption timing.

### Presentation-only

Interpolation, facing, animation, particles, sound, and screenshots are not gameplay authority.

### Abstract optimization

Threshold scheduling, lazy integration, queue compaction, and batching are compared through outcomes/invariants.

## Runs

```text
all-abstract
periodically-switched
mostly-detailed
continuously-detailed bounded control
```

## Zero-tolerance invariants

Resource conservation, no double completion, no leaked reservation, valid identity/lifecycle, one executor owner, no stale-trigger mutation, and same rule decisions for equivalent state.

## Tolerances

Values are authored project truth, justified, stable, and included in artifacts. Never tune them to hide failure.

## Observer neutrality

Compare productivity and needs as switch count changes. Report resources, work, need satisfaction, idle/blocked duration, failures, and divergence by region/mode.

## Determinism

Identical-mode reruns require exact fingerprints. Cross-mode runs require invariant equality and bounded comparison, not identical fingerprints.

## Failure

Fail on invariant difference, exceeded tolerance, incomplete/early run, or omitted required comparison.
