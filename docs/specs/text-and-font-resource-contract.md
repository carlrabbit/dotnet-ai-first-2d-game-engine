# Text and Font Resource Contract

## Authority

Authoritative for stable text resources, font metadata, raw font references, deterministic adapter-neutral measurement, glyph/text-command projection, and fingerprint exclusions.

Player-facing strings use text resource IDs where appropriate.

M021 does not implement localization, advanced shaping, bidirectional text, fallback stacks, or runtime system-font discovery.

Native glyph atlas and adapter handles do not affect semantic fingerprints.
