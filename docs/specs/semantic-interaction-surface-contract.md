# Semantic Interaction Surface Contract

## Authority

Authoritative for player-facing prompts and notifications derived from authoritative interaction candidates, condition results, semantic input actions, and post-commit events.

A prompt includes stable ID, action ID, target ID, text resource ID, enabled state, structured reason, semantic input action ID, priority, tick, and source linkage.

Prompt projection does not reevaluate gameplay conditions.

Notifications are transient, deterministic, and excluded from saves.
