# Actual Candidate Preview and Curation Contract

## Authority

Authoritative for M048 operational curation drafts, canonical materialization subjects, exact preview bundle generation, preview-before-interactive-approval semantics, modality-specific candidate preview, and preview acknowledgement/staleness.

M047 remains authoritative for canonical candidates, v2 decisions, deterministic recipes/materialization, and promotion.

## Principle

The media under human judgment must be the exact materialization subject that the interactive decision will bind.

```text
candidate + variant + typed corrections
→ materialization subject
→ exact preview
→ interactive decision
```

Do not infer correctness from candidate ID labels or session navigation.

## Materialization Subject

Canonical tuple:

```text
campaignId
candidateId
candidateFingerprint
selectedVariantId
selectedVariantFingerprint
ordered typed corrections
M047 recipe fingerprint
```

The tuple has a deterministic `materializationSubjectFingerprint`.

It is independently derivable from:

- current curation draft;
- committed M047 v2 decision;
- M047 promotion plan item.

A comparison succeeds only when those derived values are equal.

## Curation Draft

Schema:

```text
agentic2d.asset-curation-draft.v1
```

Operational fields include:

```text
candidateId
candidateFingerprint
selectedVariantId/fingerprint
typed corrections
recipe fingerprint
materializationSubjectFingerprint
previewState
acknowledgedMaterializationSubjectFingerprint
```

The draft is workbench authoring state, not approved content and not promotion authority.

Preview exploration may persist this draft for restart usability.

Changing candidate/variant/corrections invalidates any prior acknowledgement unless the canonical materialization subject remains exactly equal.

## Preview Subject and Bundle

Schemas:

```text
agentic2d.asset-preview-subject.v1
agentic2d.asset-preview-bundle.v1
agentic2d.asset-preview-observation.v1
```

The bundle contains exact media/hash/projection inputs for:

```text
base/raw candidate selection
processed/current-draft materialization
source context where relevant
```

The processed media MUST be generated by current M047 deterministic materialization logic.

The bundle is disposable and never a promoted generation.

## Image

The preview supports exact `image-file` / `image-region` subjects.

Required perceptual data:

- actual selected pixels;
- clear region/source context where helpful;
- raw/base and processed/current-draft comparison;
- crop/alpha-trim/scale effect;
- pivot/anchor overlay when present.

## Animation

The preview supports exact explicit animation sequences.

Required semantics:

- actual candidate frame regions;
- explicit selected frame order;
- M047 frame-order correction reflected in playback;
- deterministic playback/reset/step;
- actual engine animation/sampling and render projection before adapter display.

## Audio

The preview supports current WAV/PCM candidate baseline.

Required semantics:

- exact candidate/selected-variant source;
- exact M047 copy/trim processed bytes;
- manual playback only;
- raw/processed A/B;
- visible duration/trim context;
- current sound projection before adapter playback.

No auto-play.

## Interactive Approval Guard

Approval-like interactive decision requires a current preview-host acknowledgement for the exact current draft materialization subject.

Before commit, re-derive the current subject and compare it with the acknowledgement.

Mismatch/stale/error:

```text
no durable approval
stable corrective diagnostic
workbench remains usable
```

Non-approval actions may remain available under M047 decision semantics.

## Group Approval

Interactive group approval is preview-backed only when every covered exact candidate/subject has a current acknowledgement.

No unpreviewed candidate may inherit a claim of human preview merely from group membership.

## Headless Boundary

Headless v2 decisions remain valid M047 authoring authority.

They are not labeled human-preview-backed unless separately proven by an interactive M048 flow.

## Staleness

A preview acknowledgement is invalid after any change that changes materialization subject:

- candidate/source hash;
- selected variant/fingerprint;
- typed corrections;
- M047 recipe fingerprint;
- source availability/selection validity.

Host restart requires new acknowledgement even when the subject remains unchanged.

## Failure

Malformed/unsupported media produces diagnostic preview state, no current acknowledgement, and no interactive approval.

Navigation and non-approval decisions remain recoverable.

## UI Information Boundary

Humans are shown useful descriptive state:

- candidate identity;
- source-relative context;
- variant;
- typed correction summary;
- raw/processed mode;
- loading/current/stale/error;
- decision eligibility.

Humans are not required to compare hashes.

Machine evidence owns fingerprints/hashes.
