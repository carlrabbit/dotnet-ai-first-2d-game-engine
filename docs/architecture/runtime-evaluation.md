# Runtime Evaluation

## Authority

This document is authoritative for the current runtime evaluation order.

## Evaluation order

1. raylib-cs spike for quick proof of the agentic runtime loop or asset curation workbench.
2. MonoGame prototype for serious .NET 2D runtime viability.
3. SDL3/Silk.NET spike only if the project needs maximum control over the platform layer.

## Current leaning

MonoGame plus custom engine architecture is the likely serious default. raylib-cs remains useful for fast vertical slices.
