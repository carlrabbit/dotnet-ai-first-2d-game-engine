# dotnet-ai-first-2d-game-engine

This repository is the initialization skeleton for a .NET-based, AI-first 2D game engine.

The project thesis:

> Humans design, review, and make creative decisions. AI agents implement, modify, validate, and iterate through structured commands, deterministic scenarios, semantic content, and generated evidence.

The repository is intentionally initialized without .NET projects and without executable `eng/` scripts. This package is the planning and setup handoff for the first repository-creation task.

## Start here

1. Read `docs/INITIALIZATION.md`.
2. Read `AGENTS.md` for agent routing rules.
3. Use `docs/ENGINEERING.md` and `docs/engineering/command-contract.md` before creating scripts.
4. Treat `docs/research/` as non-authoritative background only.

## Current maturity

- Repository maturity: design-ready initialization skeleton.
- Target profile: artifact-first / agentic authoring + runtime/tool + game/simulation.
- Next implementation stage: create the base repository substrate, then add `eng/` scripts and initial .NET solution projects.
